BEHIND THE EVIDENCE

How ChartCourt reads a chart.

OpenCV isolates colored rectangular bars. Tesseract reads axis ticks. A linear fit converts the bar endpoints from pixel positions to numeric estimates.

  1. Find the marks. Color masks, morphology, and contours isolate aligned bars.
  2. Read the scale. At least three consistent ticks establish the numeric axis.
  3. Look again when needed. An uncertain scale triggers an enlarged, contrast-adjusted OCR pass.
  4. Check and reconstruct. Supported charts are checked for a nonzero baseline and inverted direction. The recovered values are redrawn.
The current version supports single-series, solid-color vertical bars on readable linear axes. Stacked bars, logarithmic scales, monochrome plots, and complex infographics may need review. An inverted or truncated axis is a design choice to examine, not proof of dishonesty.

Demo images are self-authored. Published dataset evaluation and AWS / COOL deployment are still pending. This local version uses OpenCV 5 and does not require an AI API key.
